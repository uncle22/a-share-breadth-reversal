# 局限、误用与统计警告

写这份文档的原因：**任何「胜率」「概率」类工具，最大的风险是被当成确定性。**

---

## 1. 结构性局限（改代码也解决不了）

### 1.1 分位需要累积

首次运行 `history.json` 是空的，报告会显示：

```
【二、历史分位】(样本 0 天)
  ⚠ 历史样本不足（需 ≥5 天），本次只做阈值判断，不出分位。
```

**这是设计上的诚实。** 想要 P20/P60/P250，先连续记录 250 个交易日。

### 1.2 5 日均需要 5 个完整交易日

盘中记录不计入基准，所以前 5 天「成交额/5日均」这一项按中性 1 分处理。

### 1.3 数据源非官方

`push2.eastmoney.com` 是东方财富网页的**内部接口**：

- 可能随时变更字段、改分页规则、加校验
- 可能限流（脚本已用 8 线程 + 分页，约 56 次请求）
- 数据本身可能延迟（盘中快照不是逐笔）

**没有 SLA，没有保证。** 建议只用于个人研究。

### 1.4 不含北交所

`fs` 参数只覆盖沪深主板 + 创业板 + 科创板。
北交所（8xxxxx / 4xxxxx）**不在样本里**，所以「全A」严格说是「沪深A」。

## 2. 方法论局限

### 2.1 广度是「慢指标」

广度告诉你「现在市场健不健康」，**不告诉你「哪天见底」**。

历史上，广度极度恶劣之后，市场可能：

- 一周内反弹（2024-02）
- 继续跌两个月（2018-10 到 2018-12）

**「极度超卖」不等于「马上涨」。**

### 2.2 单日数据噪音极大

`涨家占比` 一天之内可以从 15% 变到 45%（盘中反转）。
`TRIN` 更是如此 —— 尾盘 30 分钟的拉升能让 TRIN 从 0.6 冲到 1.1。

**所以：单日数据只用于「当日状态判断」，不用于「趋势判断」。**

### 2.3 「额价差」不能跨市场比较

同样是 +10pp：

- 在万亿成交量的牛市 → 可能是正常的板块轮动
- 在五千亿成交量的熊市 → 可能是极端抱团

**阈值是「经验值」，不是「定律」。** 建议自己回测后再调。

## 3. 常见误用清单

| ❌ 错误用法 | ✅ 正确用法 |
|---|---|
| 「TRIN < 1 就是好」 | 结合涨家占比：普跌时 TRIN 低是**抱团** |
| 「涨的股票多 = 反弹开始」 | 看**涨幅分布**：1% 的红盘和 5% 的红盘不同 |
| 「成交额大 = 资金进场」 | **放量下跌 = 出货**；放量上涨才是进场 |
| 「一天普涨 = 反转」 | 需要**连续 2–3 天** + 成交额递增 |
| 「跌停多 = 见底」 | 跌停多 = 恐慌；见底要「跌停减少 + 涨家回升」 |
| 「用主力资金替代宽度」 | 主力资金是「按单笔金额猜身份」，宽度是「按家数算广度」，**结论经常相反** |
| 「指数红 = 行情好」 | 看**额价差**：>15pp 时指数是被少数票拉的 |

## 4. 关于「胜率」和「概率」的警告

这是最重要的一节。

### 4.1 小样本的置信区间宽得可怕

假设某策略「7 次里 6 次对」，胜率 85.7%。

用 Wilson 区间算 95% 置信区间：

```
n = 7, k = 6
p̂ = 85.7%
95% CI ≈ 42% – 99%
```

**下界 42%，接近抛硬币。**

### 4.2 「样本数」不等于「独立样本数」

如果 7 个样本全部来自 **2024 年 6–8 月**，那它们很可能是**同一轮下跌的不同阶段**：

- 相关性极高
- 有效独立样本数 ≈ 1–2
- 任何「胜率」都在重复计算同一个事件

**判断标准：看样本的「时间分布」，不只看数量。**

### 4.3 「分位」不是「概率」

`P250 = 9.4` 的意思是：

> 「过去 250 天里，有 9.4% 的交易日比今天更差。」

**它不意味着「有 90.6% 的概率反弹」。**

这两句话的差别，是「描述历史」和「预测未来」的差别。

### 4.4 过拟合的三个信号

如果你在改进这个脚本，看到以下现象就该警惕：

| 信号 | 说明 |
|---|---|
| 参数调到小数点后两位才有效 | 过拟合 |
| 只在某一年有效 | 样本内偏差 |
| 「相似样本」的匹配维度超过 4 个 | 维度越多越容易找到「假相似」 |

**正确做法**：留出最近 1–2 年做**样本外验证**，只用样本内调参。

## 5. 关于「原创作者方法」的客观说明

本仓库的方法论反推自一位抖音博主的公开演示（详见 README「来源与反推过程」）。

**可以验证的部分**：TRIN、额价差、量价差、分位数 —— 公式能用真实数据复现（见 README 验算表）。

**无法验证 / 不建议照搬的部分**：

| 项 | 问题 |
|---|---|
| **7 个 KNN 同类样本** | 样本量 7，且集中在同一时期（见 §4.1、§4.2） |
| **「四组胜率对照」** | 分组标准（G1/G2/A2/C1）的定义不透明，无法复现 |
| **股指期货年化基差 −17%** | 其中约 −2%~−3% 是分红预期，剩下才是「看空/套保」，不能全算利空 |
| **COT / 美债 / 黄金** | 传导链太长，对 A 股 ETF 的日度判断噪音极大 |

**结论：学「结构」（多层验证 + 分位数标准化 + 对照组），不学「结论」。**

## 6. 本版本明确「不做」的事

| 不做 | 原因 |
|---|---|
| **预测点位** | 做不到，也不该做 |
| **预测明日涨跌** | 单日噪音太大 |
| **推荐个股** | 超出工具范围 |
| **KNN 同类样本匹配** | 样本量不足时是自欺欺人（见 §4） |
| **主力/超大单资金流替代宽度** | 口径不同，且「按金额猜身份」不可靠 |
| **自动交易** | 不接券商接口，不给下单建议 |

## 7. 如果你要改进它

优先级建议（从高到低）：

1. **加 10 日 TRIN 均线** —— 成本最低，收益最大（Arms 本人的核心用法）
2. **加 ETF 份额净申赎** —— 真实申赎，比「主力资金」可靠
3. **加广度背离检测** —— 指数新高但涨家减少，最有效的顶部信号
4. **做 250 天后回测** —— IC + 五分位 + 样本外验证
5. **多市场对比** —— 中证1000 / 创业板 / 行业内部

**每加一个指标，先问三个问题：**

- 它的「定义」有没有歧义？
- 它的「边界」（停牌、ST、新股）有没有处理？
- 它的「样本外」表现如何？
