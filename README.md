# A股 市场宽度 · 反弹真假判定

> 一个 Python 单文件，回答一个问题：**「这波反弹，是真的，还是权重拉出来的假象？」**

**方法蒸馏自抖音「布鲁斯的金融宝藏」的公开演示，独立重实现 → [来源声明](#-来源声明蒸馏自抖音布鲁斯的金融宝藏)**

给持有 ETF / 银行股、不做空、不做期权的散户用。

不预测点位，不推荐个股，只输出一个**当前状态的判定**：

```

【一、涨跌分布】
  上涨 854 | 下跌 4,246 | 平盘 117
  涨家占比 16.4%   涨额占比 36.8%   涨量占比 32.0%
  额价差 +20.4pp   量价差 +15.6pp
  TRIN_额 0.35     TRIN_量 0.43
  涨停 38 / 跌停 51
  全A成交额 7,927 亿 (交易进度 50%，全天等效 15,854 亿)

【三、六项打分】2 / 12  →  假反弹 / 下跌中继
  ❌ 涨家占比 16.4%        0分 (普跌)
  ❌ 额价差 +20.4pp        0分 (强抱团=权重拉指数)
  ⚠️ TRIN_额 0.35          1分 (极端抱团：少数票吸走资金)
  ❌ 涨停/跌停 38/51       0分 (跌停多，情绪差)

【六、结论】
  ⚠ 极致分化：涨家占比 <25% 但涨额占比明显偏高，
     指数被少数权重/题材拉着，多数股票在跌。
     这种行情里「指数红」不等于「你的票红」。
```

## 为什么需要它

散户最常见的两个错误：

1. **把「假反弹」当「反转」** → 加仓，然后套在半山腰
2. **把「真反转」当「反弹」** → 减仓，然后踏空

区别不在「涨了多少」，而在**市场宽度**：

| | 假反弹（脉冲） | 真反转 |
|---|---|---|
| 涨家占比 | 可能很高（普涨脉冲） | 高且**连续 2–3 天** |
| 涨额占比 − 涨家占比 | **差很大**（权重/抱团拉指数） | **差很小**（普惠） |
| TRIN | 接近 1 或极低（抱团） | < 0.7 且有广度支撑 |
| 成交额 | **缩量** | **放量** |
| 涨停/跌停 | 跌停 > 涨停 | 涨停 > 跌停 |

> 核心假设：**广度先于指数**。指数可以骗人，涨跌家数不会。

## 六个指标与公式

全部基于**免费公开数据**，无需任何 API Key。

| 指标 | 公式 | 回答什么 |
|---|---|---|
| **涨家占比** | 上涨家数 ÷ 有效家数 | 是不是普涨 |
| **涨额占比** | 上涨股成交额 ÷ 总成交额 | 涨的股票占了多少资金 |
| **额价差** | 涨额占比 − 涨家占比 | **是不是抱团**（差越大越集中） |
| **量价差** | 涨量占比 − 涨家占比 | 同上，用股数口径 |
| **TRIN_额** | (涨家/跌家) ÷ (涨额/跌额) | **资金偏向涨还是跌** |
| **TRIN_量** | (涨家/跌家) ÷ (涨量/跌量) | 同上，用股数口径 |

### TRIN（Arms Index，阿姆氏指标）

1967 年 Richard W. Arms Jr. 提出。两种等价写法：

```
TRIN = (上涨家数 / 下跌家数) / (上涨成交量 / 下跌成交量)

TRIN = (上涨家数 × 下跌成交量) / (下跌家数 × 上涨成交量)
```

**换算成「倍数」最好懂**：

> TRIN = 0.35 ⇔ **每只上涨股拿到的成交额，是每只下跌股的 2.9 倍**（1 ÷ 0.35）

**A 股没有官方 TRIN**（美股有 `$TRIN` / NYSE 官方指数），必须自己算 —— 这就是本脚本存在的原因之一。

### TRIN_额 vs TRIN_量 的差异本身就是信息

| 关系 | 含义 |
|---|---|
| **TRIN_额 < TRIN_量** | 上涨股**平均股价更高** → **大票在涨** |
| **TRIN_额 > TRIN_量** | 上涨股**平均股价更低** → **小票在涨** |

## 判定规则：六项打分（满分 12）

| # | 指标 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|---|
| 1 | 涨家占比 | ≥ 60% | 40–60% | < 40% |
| 2 | 额价差 | ≤ 4pp（普惠） | 4–10pp | > 10pp（强抱团） |
| 3 | TRIN_额 | **见下方条件打分** | | |
| 4 | 涨停/跌停比 | ≥ 2.0 | 0.8–2.0 | < 0.8 |
| 5 | 成交额 / 5 日均 | ≥ 1.10 | 0.90–1.10 | < 0.90 |
| 6 | 连续性（涨家占比连升天数） | ≥ 2 天 | 1 天 | 0 天 |

| 得分 | 结论 | 动作 |
|---|---|---|
| **10–12** | **真反转** | 可持有 / 回踩不破今日低点再加 |
| **7–9** | **反弹进行中** | 先不动，等第二天确认 |
| **4–6** | **弱反弹 / 分化** | 不加仓；占比 >50% 的减一点 |
| **0–3** | **假反弹 / 下跌中继** | 不抄底；占比 >50% 的必须减 |

## 结论层：两票制（v0.2 新增）

**六项打分管的是「资金面」。但原作者的系统是两层的——**

> **「资金面为大，技术面为小。技术面与资金面相反时，不开仓，等待。」**

所以 v0.2 加了一个**结论层**，把「打分」升级成「投票」：

| 票 | 怎么算 | 三态 |
|---|---|---|
| **资金面票** | 六项打分 | `0–4 → 空` / `5–8 → 中` / `9–12 → 多` |
| **技术面票** | 上证日线（收盘 vs MA20、MA5 vs MA10） | 见下 |

**技术面票的规则（写死、可复现）：**

```
收盘 > MA20 且 MA5 > MA10  →  多
收盘 < MA20 且 MA5 < MA10  →  空
其他                        →  中
```

**合并规则：**

| 资金面 | 技术面 | 结论 | 含义 |
|---|---|---|---|
| **多** | **多** | 🟢 **多** | 同向多 → 可按计划加/持有 |
| **空** | **空** | 🔴 **空** | 同向空 → 不加仓，占比高的减 |
| **多** | **空** | ⏸ **等** | **冲突 → 准备空，等两边同向** |
| **空** | **多** | ⏸ **等** | **冲突 → 准备多，等两边同向** |
| 中 / 任一 | — | 跟随非中性方 | 单边中性不算冲突 |

> **「等」是这套系统里最难执行、也最值钱的一票。**
>
> **它允许你「今天什么都不做」——而多数亏损来自「总得做点什么」。**

### 实盘示例（2026-11-18 午间）

```
【六、两票制】（资金面为大，技术面为小）
  资金面票  空    （广度 2/12）
  技术面票  空    （上证 3,570.21 | MA5 3,609.51 / MA10 3,639.18 / MA20 3,647.52）
  合  并    🔴 空
  → 同向空 → 不加仓，占比高的减
```

## 趋势指标（v0.2 新增）

| 指标 | 定义 | 读法 |
|---|---|---|
| **10 日 TRIN 均线** | 近 10 条记录的 `trin_amt` 均值 | `< 0.8` 超买 / `> 1.2` 超卖 |
| **MCL** | **McClellan Oscillator** = `EMA19(涨家−跌家) − EMA39(涨家−跌家)` | `> 0` 广度强 / `< 0` 广度弱 |

> **单日 TRIN 噪音大，10 日均才反映趋势**（Arms 本人的核心用法）。
>
> **MCL 是公开定义的指标**，不是原作者的私有黑箱——之前 README 写「未获得」是错的，已更正。

**两个指标都需要历史累积**：10 日 TRIN 需 10 天，MCL 需 39 天。样本不足时脚本会明确提示，不编造。

## 三个「反常识」口径（本项目的核心差异）

这三点是网上教程里最常被搞错、也是本脚本最值钱的地方。

### ① 盘中成交额必须按「交易进度」归一化

11:00 的 7,927 亿 **不是缩量** —— 它只走了 50% 的交易时间。

脚本用交易进度（扣除午休，240 分钟制）折算成「全天等效」，再和 5 日均比：

```
全天等效 = 盘中累计成交额 / 交易进度
```

- 线性折算误差约 ±10%，**14:45 之后结论最准**
- **只有 `progress ≥ 99%` 的完整交易日记录才进入 5 日均基准**，避免盘中数据污染历史

### ② TRIN 必须结合涨家占比解读

| 场景 | 低 TRIN 的含义 | 得分 |
|---|---|---|
| 涨家 ≥ 55%（普涨） | 资金坚决做多 | **2 分** |
| 涨家 < 55%（普跌） | **极端抱团**，少数票吸金 | **1 分** |

同样是 TRIN = 0.35：

- 在 **16% 涨家占比**下 → 是「少数票吸走资金」的警示
- 在 **70% 涨家占比**下 → 是「资金坚决」的好信号

> **把「TRIN 低」一律当好事，是最常见的误判。**

### ③ 「指数红」要单独报警

当 `涨家占比 < 25%` 且 `额价差 > 15pp`，说明指数被少数权重/题材拉着。此时结论段会先打一行「极致分化」提示。

**这种行情里「指数红」不等于「你的票红」。**

| TRIN_额 | 0.562 | (1324/4119)÷(36.39/63.61) = **0.562** | ✅ |
| TRIN_量 | 0.666 | (1324/4119)÷(32.55/67.45) = **0.666** | ✅ |

**四个指标全部吻合到小数点后两位**，说明公式反推正确。

## 想继续完善？这几个方向最有价值

### 1. 加 10 日 TRIN 均线（最简单，收益最大）

Arms 本人最看重的其实是 **10 日均 TRIN**：

- `< 0.8` → 超买
- `> 1.2` → 超卖

单日 TRIN 噪音大，10 日均才反映趋势。只需在 `history.json` 里累计 `trin_amt` 后取均值。

### 2. 加 ETF 份额净申赎（比「主力资金」可靠）

`主力资金` 是「按单笔成交金额猜身份」，而**份额变化是真实申赎**。

- 沪市：归属日份额 − 前一交易日份额，× 归属日单位净值
- 深市：下一交易日份额记录 − 归属日份额记录，× 归属日单位净值
- 数据源：东财「基金份额」接口

> 参考实现思路：[FTShare-Lab/FtShare_fincase](https://github.com/FTShare-Lab/FtShare_fincase)（MIT，需要付费 API Key，本仓库未采用）

### 3. 广度背离检测

**指数创新高，但上涨家数在减少** = 顶部背离。这是广度分析最有效的用法之一，本版本还没做。

### 4. 历史回测（IC / 五分位）

把 `history.json` 养成 250 天以上后，可以做：

- 单指标 IC（指标与未来 N 日收益的相关系数）
- 五分位分层（把指标分 5 组，看各组收益）
- 组合信号胜率

注意：**一定要留出样本外**，否则就是过拟合。

### 5. 多市场对比

同样的口径可以套到：
- 中证 1000 / 创业板 / 科创 50 的成分股
- 行业板块内部（比如只看半导体）

#### 为什么加「成交前十集中度」

来自**另一份独立的解读稿**（某商业产品「策研AI」对同一系统的 18 页反推，
该产品仍在内测、未开源）。它列了八项市场指标，其中这一项**性价比最高**：

- 一次快照就能算，不需要逐只历史
- 比「额价差」更直白

**读法：**

```
均匀分布下，前 10 只票应该占 10 / 家数。
11/18：家数 5,565，均匀分布 = 0.18%
实际   = 6.92%
倍数   = 38 倍
```

> **14:59 的实测值 6.92% = 均匀分布的 38 倍。**
> **意思是：5,565 只票里，前 10 只吸走了全场 7% 的钱。**

**⚠️ 盘中不可比**：开盘初期只有一部分股票在成交，前十自然占比更高
（10:12 实测 9.93%）。**这个数只有在收盘时才是可比的。**

#### 为什么加「护盘式假红盘」

**11-18 正是这种日子：**

| 指标 | 值 |
|---|---|
| 上证 | **+0.09%（红）** |
| 涨家占比 | **24.7%** |
| 额价差 | **+23.7pp** |
| 跌停 | **65 只** |

**旧版本只会说「极致分化」，新版本直接说：**

```
🚨 护盘式假红盘：上证 +0.09%（红），但涨家只 24.7%、额价差 +23.7pp。
   意思是：75% 的股票在跌，资金在强行拉指数。
   这不是反弹，是「指数体面、账户难看」。
```

#### 量能安全阀（修 bug）

**旧版在开盘 10 分钟就会算出「放量 ×1.82」——这是错的。**

A 股成交量是 U 型分布：开盘 18% 的时间里，成交量远超 18%。
线性外推会把「开盘活跃」误判成「全天放量」。

**修法：交易进度 <50% 时不折算，直接输出「过早，暂不折算」。**

**背离的判定：**

```
指数 20 日上涨 + 涨家占比 20 日下降  →  顶背离（指数在涨，广度在退）
指数 20 日下跌 + 涨家占比 20 日上升  →  底背离（指数在跌，广度在改善）
```

> **顶背离是广度分析里最有效的顶部信号**——指数好看，但参与的股票在减少。

**为什么暂缓「资本1（股债息差）」：**

免费接口拿不到沪深 300 的 PE / 股息率：

- 东财 `f9` / `f162`（市盈率/市净率）对**指数**返回 `0`
- 东财 `RPT_BOND_CB_LIST` 报错「BOND_TYPE 列不存在」
- 中债/中证官网需要另行抓取，且结构不稳定

**宁可留白，也不编造数据。** 要做的话有两条路：
① 接付费数据源；② 手工维护 `data/macro.json`（10Y 国债 + 沪深300 PE，每周更新一次）。
